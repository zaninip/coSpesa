# CoSpesa 🛒

A collaborative shopping list web app that lets you create, share, and manage shopping lists with friends and family in real-time.

🌐 **Live Demo**: [https://co-spesa.vercel.app/](https://co-spesa.vercel.app/)

## ✨ Features

- **Shared Shopping Lists** - Create lists and share them with a simple 6-character code
- **Real-time Collaboration** - Multiple users can add and check off items simultaneously
- **Smart History** - Quick-add frequently purchased items based on your shopping history
- **Multi-language** - Available in Italian, English, French, and Spanish
- **Mobile-Friendly** - Responsive design that works great on any device

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **Backend**: [Supabase](https://supabase.com) (PostgreSQL, Authentication, Real-time)
- **Deployment**: [Vercel](https://vercel.com)
- **Icons**: Lucide Icons

## 📱 Pages

- **Login/Signup** - Secure authentication
- **Dashboard** - Overview of all your shopping lists
- **Shopping List** - Add, check off, and remove items
- **History** - View purchase statistics and frequently bought items

## 🔒 Security

- Row Level Security (RLS) policies
- Supabase Authentication
- Protected routes with session validation
